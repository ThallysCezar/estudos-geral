A definição de “feito”.

1. Funciona no caminho feliz

O MVP executa localmente por um comando, possui dados de exemplo e um teste automatizado que prova o caso principal.

2. Falha sem esconder

Você injeta timeout, duplicidade, concorrência, indisponibilidade ou mensagem inválida e consegue explicar o comportamento observado.

3. A decisão fica legível

README reproduzível, diagrama, ADR curta, comandos, limites conhecidos e evidências de testes. O projeto deve sobreviver à sua memória.

4. Cloud nunca é pré-requisito

LocalStack, MinIO, Ollama, PostgreSQL, RabbitMQ, kind ou Testcontainers mantêm o laboratório local. Conta real é extensão opcional, sempre com orçamento, alerta e teardown.

5. FinLab usa somente dados sintéticos

Os exemplos financeiros servem para exercitar precisão, transações e confiabilidade. Não conecte conta bancária, corretora, cartão ou ordem de investimento real ao laboratório.

6. Teoria e bancada são o mesmo estudo

Ler sem construir vira reconhecimento: você acha que sabe porque a explicação pareceu clara. Construir sem ler vira repetição: funciona e você não sabe por quê. Todo projeto aqui abre com o link do documento que explica o que ele exercita.
