Como Obter Suas Chaves de API Gratuitas

Para usar o Prompt Studio e o Formatador de Texto sem pagar nada, você pode gerar chaves gratuitas diretamente nos três maiores provedores com suporte aberto para desenvolvedores. Suas chaves ficam salvas 100% no seu navegador (armazenamento local) e nunca são enviadas a terceiros.

⚡ 1.500 req/dia Free

Google AI Studio (Gemini)

Modelos Gemini 2.5 Flash, 2.5 Pro e 3.5 Flash. Ideal para raciocínio profundo, multimodalidade e análise de código.
🚀 800 tokens/s (LPU)

Groq Cloud (Free LPU)

Execução instantânea de modelos de ponta como Llama 3.3 70B e DeepSeek R1 com latência quase nula.
🌐 Modelos :free

OpenRouter Free Hub

Acesso via rota gratuita a múltiplos modelos open-source (Llama 3.3 70B, DeepSeek R1, Qwen 2.5 Coder).

1. Google AI Studio (Google Gemini)

Modelos: gemini-2.5-flash · gemini-2.5-pro · gemini-3.5-flash
Abrir Google AI Studio ↗
Custo 100% Gratuito (Sem Cartão)
Limite Diário Gratuito 1.500 requisições por dia
Limite por Minuto 15 requisições / min
Formato da Chave AIzaSy... (39 caracteres)
01

Acesse o Google AI Studio

Entre no link oficial: aistudio.google.com/app/apikey e faça login com qualquer conta Google (Gmail pessoal ou corporativa).

02

Crie sua Chave de API

Clique no botão azul superior "Create API key" (ou "Get API key"). Em seguida, selecione "Create API key in new project" para criar um projeto GCP isolado e gratuito automaticamente.

03

Copie a Chave Gerada

Uma janela modal exibirá uma chave começando com AIzaSy.... Clique no ícone de cópia 📋 e cole no campo de Chave da API no Prompt Studio ou no Formatador.

💡 Dica Pro: Se você tiver faturamento ativado (Google Cloud Billing), sua chave também terá acesso aos modelos gemini-2.5-pro sem limites restritos de requisições por minuto.
🚀

2. Groq Cloud (Free LPU)

Modelos: llama-3.3-70b-versatile · deepseek-r1-distill-llama-70b · llama-3.1-8b-instant
Abrir Groq Console ↗
Custo 100% Gratuito (Sem Cartão)
Velocidade de Geração ~500 a 800 tokens / segundo
Modelo Recomendado llama-3.3-70b-versatile
Formato da Chave gsk_... (56 caracteres)
01

Acesse o Console da Groq

Acesse console.groq.com/keys e faça login rápido com sua conta GitHub ou Google.

02

Gere uma API Key

No menu lateral esquerdo, clique em "API Keys" e em seguida no botão "Create API Key". Dê um nome qualquer para sua chave (ex: PromptStudio) e confirme.

03

Copie a Chave Imediatamente

A Groq exibe a chave completa iniciando com gsk_... apenas uma vez por motivos de segurança. Copie e cole na aba "🚀 Groq Cloud" da nossa ferramenta.

⚡ Por que a Groq é tão rápida? A Groq não usa GPUs tradicionais da Nvidia. Ela utiliza LPUs (Language Processing Units) desenhadas especificamente para processamento de linguagem, entregando respostas quase instantâneas.
🌐

3. OpenRouter (Modelos Gratuitos :free)

Modelos: meta-llama/llama-3.3-70b-instruct:free · deepseek/deepseek-r1:free
Abrir OpenRouter Keys ↗
Custo Rota ':free' 100% Gratuita
Modelos Disponíveis Llama 3.3, DeepSeek R1, Qwen
Cartão Exigido Não (Saldo $0 permitido)
Formato da Chave sk-or-v1-... (73 caracteres)
01

Acesse o OpenRouter

Visite openrouter.ai/keys e conecte com sua conta Google, GitHub ou Discord.

02

Crie sua Chave de Acesso

Clique em "Create Key". Dê um nome identificador e deixe o limite de crédito em branco ou padrão ($0).

03

Cole na Ferramenta

Copie a chave gerada sk-or-v1-... e cole na aba "🌐 OpenRouter". Ao usar os modelos marcados com :free, você não gasta nenhum centavo.

🛡️

Segurança & Privacidade: Como suas chaves são tratadas?

Todas as ferramentas deste portal utilizam a arquitetura BYOK (Bring Your Own Key) diretamente no navegador. Suas chaves são salvas estritamente no seu localStorage e as chamadas vão do seu computador diretamente para a API oficial do provedor (Google, Groq ou OpenRouter). Nenhuma chave é gravada em servidores intermediários ou em arquivos comitados no repositório.
